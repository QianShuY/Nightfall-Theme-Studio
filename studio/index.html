INSTALLATION

如何应用到客户端？

双击「安装并启动Nightfall.bat」，连接到本地主题桥接工具后，选择主题点击「一键应用到 ChatGPT」。首次使用需要已安装兼容的第三方客户端插件运行时。Windows 官方客户端没有公开的完整换肤 API，插件模式依赖第三方注入运行时并且尚未在你的具体客户端版本上验证。

  1. 双击「安装并启动Nightfall.bat」打开工具。
  2. 如状态显示未就绪，请先自行了解、安装兼容的第三方 renderer-tweak 运行时。
  3. 点击「连接客户端」，工具会将 Nightfall 插件复制到对应目录。
  4. 点击「一键应用到 ChatGPT」，刷新/重启支持的客户端查看效果。

不建议为了换肤关闭系统安全防护；无法兼容时使用浏览器扩展方案。
