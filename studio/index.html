INSTALLATION

如何应用到客户端？

Nightfall Studio 是离线设计器。你可以直接编辑并导出皮肤 JSON，随后在桌面插件的设置页导入。Windows 官方客户端没有公开的完整换肤 API，插件模式依赖第三方注入运行时并且尚未在你的具体客户端版本上验证。

  1. 先在此处编辑并导出 JSON。
  2. 阅读项目 README，安装可用的第三方 renderer-tweak 运行时。
  3. 将 desktop-tweak 的 manifest.json、index.js 安装到运行时的 tweaks 目录。
  4. 打开运行时提供的 Nightfall 设置页，导入刚才的主题。

不建议为了换肤关闭系统安全防护；无法兼容时使用浏览器扩展方案。
